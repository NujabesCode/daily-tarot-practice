# 10. 소울카드 소개 화면

## 목표
![](images/06_soul_intro.png)

설명 글(일부 단어는 노란색), 선택한 날짜 버튼, **"달 10개로 소울카드 찾기"** 버튼을 만듭니다.

## 화면 분석
| 요소 | 만드는 방법 |
|---|---|
| 위·아래 구름, 달은 없음 | `TarotBackground(showMoon = false, showTopClouds = true)` |
| 왼쪽 위 `<` | `Icon` + `clickable` |
| "소울 넘버", "소울 카드" 등 **노란 글씨** | `buildAnnotatedString` + `withStyle(SpanStyle(color = Gold))` |
| "2026년 4월 1일 >" 테두리 버튼 | 누르면 달력으로 돌아감 |
| "● 달 10개로 소울카드 찾기" | 노란 원 + 글자, 그라데이션 알약 버튼 |
| 아래 작은 회색 안내 문구 | `fontSize = 10.sp`, `Dim` 색 |

## 따라하기

### 1) 새 파일 `SoulIntroScreen.kt`

```kotlin
package com.example.dailytarot

import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.shape.CircleShape
import androidx.compose.material3.Icon
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.clip
import androidx.compose.ui.draw.rotate
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.res.painterResource
import androidx.compose.ui.text.SpanStyle
import androidx.compose.ui.text.buildAnnotatedString
import androidx.compose.ui.text.font.FontFamily
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.text.style.TextAlign
import androidx.compose.ui.text.withStyle
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import java.time.LocalDate

fun koreanDate(d: LocalDate) = "${d.year}년 ${d.monthValue}월 ${d.dayOfMonth}일"

@Composable
fun SoulIntroScreen(
    birth: LocalDate,
    onBack: () -> Unit,
    onDateClick: () -> Unit,
    onFind: () -> Unit
) {
    // 일부 단어만 노란색으로
    val introText = buildAnnotatedString {
        fun gold(s: String) = withStyle(SpanStyle(color = Gold)) { append(s) }
        gold("소울 넘버")
        append("는 생년월일의 숫자를 모두 더해\n얻는 최종적인 한 자리 숫자로,\n당신의 핵심적인 에너지와 삶의 테마를 나타냅니다.\n이 소울 넘버에 해당하는\n메이저 아르카나 타로 카드가 바로 ")
        gold("소울 카드")
        append("이며,\n이는 당신의 타고난 성격, 기질,\n그리고 삶의 목적을 상징합니다.\n즉, 소울 넘버는 당신의 ")
        gold("영혼의 번호")
        append("이고,\n소울 카드는 그 번호가 의미하는\n")
        gold("영혼의 본질")
        append("을 보여주는 상징인 셈입니다.")
    }

    TarotBackground(showMoon = false, showTopClouds = true) {
        Column(
            Modifier
                .fillMaxSize()
                .padding(horizontal = 16.dp),
            horizontalAlignment = Alignment.CenterHorizontally
        ) {
            Spacer(Modifier.height(56.dp))
            LogoMark()
            Spacer(Modifier.height(4.dp))
            Text(
                "나의 생일로 알아보는 소울카드",
                color = Color.White,
                fontSize = 20.sp,
                fontFamily = FontFamily.Serif,
                fontWeight = FontWeight.Bold
            )
            Spacer(Modifier.height(32.dp))
            Text(
                introText,
                color = Color.White,
                fontSize = 13.sp,
                lineHeight = 26.sp,
                textAlign = TextAlign.Center
            )
            Spacer(Modifier.height(32.dp))

            // 날짜 버튼 (누르면 달력으로 돌아감)
            Row(
                Modifier
                    .width(180.dp)
                    .clip(CircleShape)
                    .border(1.dp, Color(0xB3FFFFFF), CircleShape)
                    .clickable(onClick = onDateClick)
                    .padding(horizontal = 20.dp, vertical = 12.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                Text(koreanDate(birth), color = Color.White, fontSize = 14.sp, modifier = Modifier.weight(1f))
                Icon(
                    painterResource(R.drawable.ic_back),
                    contentDescription = null,
                    tint = Color.White,
                    modifier = Modifier.size(16.dp).rotate(180f)
                )
            }
            Spacer(Modifier.height(28.dp))

            // 달 10개로 소울카드 찾기
            Row(
                Modifier
                    .clip(CircleShape)
                    .background(Brush.horizontalGradient(listOf(Color(0xFF6E4C86), Color(0xFF3E1A62))))
                    .clickable(onClick = onFind)
                    .padding(horizontal = 24.dp, vertical = 14.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                Box(
                    Modifier
                        .size(16.dp)
                        .clip(CircleShape)
                        .background(Brush.radialGradient(listOf(Color(0xFFFFFDE7), Color(0xFFF6C453))))
                )
                Spacer(Modifier.width(10.dp))
                Text("달 10개로 소울카드 찾기", color = Color.White, fontSize = 15.sp, fontWeight = FontWeight.Bold)
            }
            Spacer(Modifier.height(12.dp))
            Text(
                "소울카드에 사용되는 정보는\n카드 조합 용도 외에 사용되지 않습니다.",
                color = Dim,
                fontSize = 10.sp,
                lineHeight = 14.sp,
                textAlign = TextAlign.Center
            )
        }

        // 왼쪽 위 뒤로가기 (Column보다 나중에 써야 위에 올라와서 눌린다)
        Icon(
            painterResource(R.drawable.ic_back),
            contentDescription = "뒤로",
            tint = Color.White,
            modifier = Modifier
                .padding(16.dp)
                .size(28.dp)
                .clickable(onClick = onBack)
        )
    }
}
```

### 코드 설명

**① 한 문장 안에서 일부만 색 바꾸기**
```kotlin
buildAnnotatedString {
    withStyle(SpanStyle(color = Gold)) { append("소울 넘버") }  // 노란색
    append("는 생년월일의 ...")                                  // 기본색
}
```
매번 `withStyle`을 쓰면 길어서 `gold("...")`라는 작은 함수를 만들어 썼습니다.

**② 줄바꿈**: 원본 화면과 같은 위치에서 줄이 바뀌도록 `\n`을 직접 넣었습니다.

**③ 뒤로가기 아이콘을 맨 마지막에 쓴 이유**
`Box` 안에서는 **나중에 쓴 것이 위에** 올라옵니다. `Column`이 화면 전체를 덮기 때문에, 아이콘을 먼저 쓰면 `Column` 아래에 깔려서 잘 안 눌릴 수 있습니다.

### 2) `MainActivity.kt` 수정

**(1) `TarotApp()` 맨 위에 두 줄 추가** (`var screen ...` 바로 위)
```kotlin
    val context = LocalContext.current
```
그리고 `var user ...` 줄 **아래**에:
```kotlin
    var moons by remember { mutableIntStateOf(30) }            // 가진 달 개수
```

**(2) `Screen.SOUL_INTRO` 줄 바꾸기**

바꾸기 전
```kotlin
        Screen.SOUL_INTRO -> TempScreen("소울카드 소개 (10단계에서 만들어요)", onClick = { screen = Screen.RESULT })
```
바꾼 후
```kotlin
        Screen.SOUL_INTRO -> SoulIntroScreen(
            birth = user.birth!!,
            onBack = { goBack() },
            onDateClick = { goBack() },
            onFind = {
                if (moons >= 10) {
                    moons -= 10
                    screen = Screen.RESULT
                } else {
                    Toast.makeText(context, "달이 부족해요.", Toast.LENGTH_SHORT).show()
                }
            }
        )
```

**(3) import 추가** (빨간 줄이 나오면 Alt + Enter로 넣어도 됩니다)
```kotlin
import android.widget.Toast
import androidx.compose.ui.platform.LocalContext
```

> 💡 `user.birth!!`: 원래 `birth`는 비어 있을 수 있는(`LocalDate?`) 값입니다. 이 화면에는 **달력에서 날짜를 고른 뒤에만** 오니까 "절대 비어 있지 않다"는 뜻으로 `!!`를 붙입니다.

## ✅ 실행해서 확인
- [ ] 달력에서 날짜를 고르면 소개 화면이 나온다
- [ ] "소울 넘버", "소울 카드", "영혼의 번호", "영혼의 본질"이 노란색이다
- [ ] 날짜 버튼에 고른 날짜가 "2026년 4월 1일" 형식으로 나온다
- [ ] 날짜 버튼이나 `<`를 누르면 달력으로 돌아간다
- [ ] "달 10개로 소울카드 찾기"를 누르면 결과 임시 화면으로 간다
- [ ] 결과 → 돌아오기 → 찾기를 **4번째** 누르면 "달이 부족해요." (30개 → 20 → 10 → 0)
