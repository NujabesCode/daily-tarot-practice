# A11. Module A 제출 연습 · 채점기준 체크리스트

## 1. 제출 연습 (15분 안에)

> 실제 대회에서는 **종료 15분 전에 코딩을 멈추고** 이 순서를 시작합니다. 연습 때도 타이머를 켜고 해 보세요.

### ① APK 빌드
1. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
   (버전에 따라 **Build → Generate App Bundles or APKs → Generate APKs**)
2. 오른쪽 아래 알림 **locate** 클릭 → `app/build/outputs/apk/debug/app-debug.apk`

### ② 이름 바꿔서 루트로
- `app-debug.apk`를 **프로젝트 폴더 맨 위(루트)** 에 복사하고 이름을 바꿉니다.
- 선수 번호가 `07`이라면: `Module_A_07.apk`

```
C:\contest\DailyTarot_A\         ← 프로젝트 루트
  app\
  gradle\
  build.gradle.kts
  settings.gradle.kts
  Module_A_07.apk                ← 여기!
```

### ③ 제출한 APK로 직접 확인
1. 실행 중인 앱을 에뮬레이터에서 **삭제**합니다. (앱 아이콘 길게 누르기 → 제거)
2. `Module_A_07.apk` 파일을 에뮬레이터 화면으로 **드래그 앤 드롭** → 설치
3. 앱 서랍에서 **아이콘과 이름** 확인 → 실행해서 처음부터 끝까지 한 번
   - 채점은 **제출한 APK로** 합니다. Run 버튼으로 본 것과 APK가 다르면 APK 기준입니다.

### ④ USB로 복사
- **Android Studio를 닫고** 프로젝트 폴더 **전체**를 USB에 복사합니다. (열린 상태에서 복사하면 잠긴 파일 때문에 실패할 수 있음)
- 용량을 줄이고 싶다면 `build`, `.gradle` 폴더는 빼도 됩니다. **APK는 루트에 있으니 함께 갑니다.**
- USB에서 폴더를 열어 **APK가 루트에 있는지** 마지막으로 확인합니다.

### 자주 하는 실수

| 실수 | 결과 |
|---|---|
| APK를 `app/build/...` 안에 그대로 둠 | "APK 파일명 규칙" 0점, 평가 지연 |
| `Module-A-07.apk`, `ModuleA_07.apk` | 파일명 규칙 0점 |
| 마지막에 코드를 고치고 APK를 다시 안 빌드 | 고친 내용이 반영 안 된 APK로 채점 |
| 제출 시간 1분 초과 | "시간 내 제출" 0점 + 이후 변경 불가 |

## 3. 변형 문제 대비 (연습용)

대회 당일 과제가 조금 바뀌어 나올 수 있습니다. 시간이 남으면 아래를 직접 바꿔 보세요.

| 변형 | 어디를 고치나 |
|---|---|
| 이름은 **한글만** 허용 | `NameScreen.submit()`에 `Regex("^[가-힣]+$")` 검사 + "이름은 한글로만 입력해주세요." |
| 나이 범위 14~100 | `AgeScreen.submit()`의 `1..120` |
| 진행 표시줄을 **점 5개**로 | `StepProgress`의 `Box`를 `CircleShape` 원으로 |
| 시간 → 분 단위를 **1분**으로 | `ClockFace` 라벨 60개 + `atan2` 각도 ÷ 6도 |
| 달력에 **요일 머리글(일~토)** 추가 | `MonthCalendar` 위에 `Row`로 7칸 |
| 입력 값 **앱 재시작 후에도 유지** | `SharedPreferences` (B02 방식) |
