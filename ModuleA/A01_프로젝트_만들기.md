# A01. 프로젝트 만들기 · 앱 이름 · 앱 아이콘

## 목표
- Compose 프로젝트를 만들고
- 채점 항목 **"앱 이름 Daily Tarot"**, **"앱 아이콘 app_icon.png"** (1점)를 바로 끝냅니다.

## 1) 새 프로젝트

1. Android Studio → **New Project** → **Empty Activity** (Compose 아이콘이 있는 것)
2. 설정
   | 항목 | 값 |
   |---|---|
   | Name | `Daily Tarot` |
   | Package name | `com.example.dailytarot` |
   | Save location | 예: `C:\contest\DailyTarot_A` (모듈마다 폴더를 따로 둡니다) |
   | Language | Kotlin |
   | **Minimum SDK** | **API 26** (날짜 계산에 `java.time`을 쓰기 위해) |
   | Build configuration language | Kotlin DSL |
3. **Finish** → Gradle 동기화가 끝날 때까지 기다립니다.

> ⚠️ `app/build.gradle.kts`의 `dependencies`에 **아무것도 추가하지 않습니다.** 기본으로 들어 있는 것만 씁니다.

## 2) 앱 이름

`app/src/main/res/values/strings.xml`

```xml
<resources>
    <string name="app_name">Daily Tarot</string>
</resources>
```

프로젝트 이름을 `Daily Tarot`으로 만들었다면 이미 이렇게 되어 있습니다. **띄어쓰기와 대소문자**까지 확인하세요.

## 3) 앱 아이콘

1. 왼쪽 프로젝트 창에서 `app` 폴더 **오른쪽 클릭 → New → Image Asset**
2. 설정
   | 항목 | 값 |
   |---|---|
   | Icon Type | Launcher Icons (Adaptive and Legacy) |
   | Name | `ic_launcher` (그대로) |
   | Foreground Layer → Source Asset → Asset Type | **Image** |
   | Path | 제공 파일 `공통제공파일/images/app_icon.png` |
   | Trim | No |
   | Resize | 아이콘이 동그라미 안에 다 들어오도록 조절 (보통 70~80%) |
   | Background Layer | Color, `#3D1466` (보라) |
3. **Next → Finish** (덮어쓰기 경고가 나오면 그대로 진행)

## 4) 세로 화면 고정

`app/src/main/AndroidManifest.xml`의 `<activity>`에 한 줄 추가합니다.

```xml
<activity
    android:name=".MainActivity"
    android:exported="true"
    android:screenOrientation="portrait"
    android:theme="@style/Theme.DailyTarot">
```

`android:icon="@mipmap/ic_launcher"`, `android:label="@string/app_name"`이 `<application>`에 있는지도 확인합니다.

## ✅ 실행해서 확인

1. 위쪽 기기 선택에서 **Pixel 5 API 33** AVD 선택 → ▶ Run
2. 홈 화면(앱 서랍)으로 나가서 확인
   - [ ] 아이콘이 `app_icon.png` 그림이다
   - [ ] 아이콘 아래 이름이 **Daily Tarot** 이다
