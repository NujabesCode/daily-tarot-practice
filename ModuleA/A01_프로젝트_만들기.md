# A01. 프로젝트 만들기 · 앱 이름 · 앱 아이콘

## 목표
- Compose 프로젝트를 만들고
- 채점 항목 **"앱 이름 Daily Tarot"**, **"앱 아이콘 app_icon.png"** (1점)를 바로 끝냅니다.

## 1) 새 프로젝트

1. Android Studio → **New Project** → **Empty Activity** (Compose 아이콘이 있는 것)
2. 설정
   | 항목 | 값 |
   |---|---|
   | Name | `Daily Tarot` |
   | Package name | `com.example.dailytarot` |
   | Save location | 예: `C:\contest\DailyTarot_A` (모듈마다 폴더를 따로 둡니다) |
   | Language | Kotlin |
   | **Minimum SDK** | **API 26** (날짜 계산에 `java.time`을 쓰기 위해) |
   | Build configuration language | Kotlin DSL |
3. **Finish** → Gradle 동기화가 끝날 때까지 기다립니다.

> ⚠️ `app/build.gradle.kts`의 `dependencies`에 **아무것도 추가하지 않습니다.** 기본으로 들어 있는 것만 씁니다.

## 2) 앱 이름

`app/src/main/res/values/strings.xml`

```xml
<!-- resources: 앱에서 쓰는 "값"(글자, 색, 숫자 등)을 모아 두는 파일의 맨 바깥 틀 -->
<resources>
    <!-- string: 글자 하나를 등록한다.
         name="app_name" → 이 글자의 이름(코드·XML에서 @string/app_name 으로 부름)
         Daily Tarot      → 실제 값. AndroidManifest의 android:label 이 이 값을 가져가서
                            앱 서랍의 아이콘 아래 이름으로 보여 준다. (채점: 앱 이름 0.5점) -->
    <string name="app_name">Daily Tarot</string>
</resources>
```

프로젝트 이름을 `Daily Tarot`으로 만들었다면 이미 이렇게 되어 있습니다. **띄어쓰기와 대소문자**까지 확인하세요.

## 3) 앱 아이콘

1. 왼쪽 프로젝트 창에서 `app` 폴더 **오른쪽 클릭 → New → Image Asset**
2. 설정
   | 항목 | 값 | 무슨 뜻인가 |
   |---|---|---|
   | Icon Type | Launcher Icons (Adaptive and Legacy) | 앱 서랍·홈 화면에 보이는 **실행 아이콘**을 만든다. Adaptive = 안드로이드 8.0+ (모양을 기기가 동그라미·둥근 사각형 등으로 잘라 씀), Legacy = 그 이전 기기용 |
   | Name | `ic_launcher` (그대로) | 만들어질 파일 이름. Manifest가 `@mipmap/ic_launcher`로 이 이름을 찾으므로 **바꾸지 않는다** |
   | Foreground Layer → Source Asset → Asset Type | **Image** | 아이콘 앞쪽 그림을 그림 파일로 지정 (Clip Art·Text가 아니라) |
   | Path | `공통제공파일\images\app_icon.png` | 대회 선수 제공 폴더 안의 파일. 예: `C:\Users\…\2026_지방대회_선수제공파일_모바일앱개발\공통제공파일\images\app_icon.png` |
   | Trim | No | 그림 바깥 여백을 자동으로 잘라내지 않는다 (원본 모양 유지) |
   | Resize | 아이콘이 동그라미 안에 다 들어오도록 조절 (보통 70~80%) | Adaptive 아이콘은 가장자리가 잘리므로, 미리보기의 동그라미 안에 그림이 다 보이게 줄인다 |
   | Background Layer | Color, `#3D1466` (보라) | 앞 그림 뒤에 깔리는 배경. 앱 배경과 같은 보라색 |
3. **Next → Finish** (덮어쓰기 경고가 나오면 그대로 진행)
   → `res/mipmap-…` 폴더들에 `ic_launcher`, `ic_launcher_round`가 해상도별로 만들어집니다.

## 4) 세로 화면 고정 · AndroidManifest.xml 이해하기

### AndroidManifest.xml이 뭔가요?
앱의 **신분증**입니다. 안드로이드 시스템은 앱을 설치·실행할 때 이 파일을 먼저 읽고
"앱 이름이 뭔지, 아이콘이 뭔지, 처음에 어떤 화면(Activity)을 띄우는지, 화면을 돌려도 되는지"를 알아냅니다.
코드(`.kt`)가 아니라 **설정 파일**이라서, 여기서 바꾼 내용은 앱 동작 방식 자체를 바꿉니다.

### 할 일
`app/src/main/AndroidManifest.xml`을 열고, `<activity` 태그 안에 **`android:screenOrientation="portrait"` 한 줄만** 추가합니다.
나머지 줄은 새 프로젝트를 만들 때 이미 들어 있습니다.

> ⚠️ **XML 주석(`<!-- -->`)은 태그 안 속성 사이에 넣을 수 없습니다.** (`<activity` 와 `>` 사이에 주석을 넣으면 빌드 에러)
> 그래서 아래 예시는 설명을 **태그 위에** 적었습니다. 실제 파일에는 주석을 안 적어도 됩니다.

완성된 파일 전체 (주석 = 설명):

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- ↑ 이 파일이 XML 형식이고 글자는 UTF-8(한글 가능)이라는 선언 -->

<!-- manifest: 파일 전체를 감싸는 맨 바깥 태그
     xmlns:android = "android:" 로 시작하는 속성들이 안드로이드 공식 속성이라는 선언 (지우면 안 됨)
     xmlns:tools   = "tools:" 로 시작하는 속성은 Android Studio 전용 힌트 (앱 실행에는 영향 없음) -->
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools">

    <!-- application: 앱 전체에 적용되는 설정
         allowBackup        = 구글 계정 백업 허용 여부 (대회와 무관, 그대로 둠)
         dataExtractionRules, fullBackupContent = 백업할 파일 규칙 (그대로 둠)
         icon               = 앱 아이콘. 3)에서 만든 @mipmap/ic_launcher  ← 채점: 앱 아이콘
         label              = 앱 이름. 2)의 @string/app_name = "Daily Tarot" ← 채점: 앱 이름
         roundIcon          = 동그란 아이콘을 쓰는 기기용 아이콘 (Image Asset이 같이 만들어 줌)
         supportsRtl        = 아랍어처럼 오른쪽→왼쪽 언어 지원 (그대로 둠)
         theme              = 앱 기본 테마(상태바 색 등). 화면은 Compose로 그리므로 거의 영향 없음
         tools:targetApi    = Android Studio 경고용 힌트 (그대로 둠) -->
    <application
        android:allowBackup="true"
        android:dataExtractionRules="@xml/data_extraction_rules"
        android:fullBackupContent="@xml/backup_rules"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:supportsRtl="true"
        android:theme="@style/Theme.DailyTarot"
        tools:targetApi="31">

        <!-- activity: 화면 하나를 담는 "창". 이 앱은 MainActivity 하나 안에서
                       Compose로 모든 화면(온보딩, 입력, 홈…)을 바꿔 그린다.
             name              = 이 창을 담당하는 클래스. ".MainActivity" = 패키지(com.example.dailytarot) 안의 MainActivity.kt
                                 → 클래스 이름을 바꾸면 여기도 바꿔야 함. 틀리면 앱 실행 즉시 종료
             exported          = 다른 앱(=휴대폰 홈 화면 런처)이 이 창을 열 수 있는지.
                                 앱 아이콘을 눌러 실행하려면 반드시 "true"
                                 (아래 intent-filter가 있으면 API 31+에서는 꼭 적어야 함, 없으면 빌드 에러)
             screenOrientation = ★ 이번에 추가하는 줄. 화면 방향 고정.
                                 "portrait" = 세로 고정 → 에뮬레이터를 돌려도 화면이 안 돌아감
                                 (돌아가면 레이아웃이 깨지고, Activity가 다시 만들어지며 입력값이 날아갈 수 있음)
                                 다른 값: "landscape"(가로 고정), "unspecified"(기본, 돌아감)
             theme             = 이 창에만 적용할 테마. 보통 application과 같은 값 -->
        <activity
            android:name=".MainActivity"
            android:exported="true"
            android:screenOrientation="portrait"
            android:theme="@style/Theme.DailyTarot">

            <!-- intent-filter: "어떤 요청이 오면 이 창을 열지" 조건표 -->
            <intent-filter>
                <!-- action MAIN = 이 앱의 시작 화면이다 -->
                <action android:name="android.intent.action.MAIN" />
                <!-- category LAUNCHER = 앱 서랍에 아이콘을 만들어라
                     → MAIN + LAUNCHER 두 줄이 있어야 아이콘이 생기고, 누르면 이 창이 열린다 -->
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

> 💡 Android Studio 버전에 따라 `<activity>`에 `android:label="@string/app_name"`이 더 있을 수 있습니다. 그대로 두면 됩니다.
> 💡 `screenOrientation` 줄에 노란 밑줄(경고)이 생길 수 있습니다. "큰 화면 기기에서는 방향 고정을 권장하지 않는다"는 **권고**일 뿐이라 빌드·실행에는 문제 없습니다.

### 꼭 확인할 3가지

| 확인 | 왜 |
|---|---|
| `<application>`에 `android:icon="@mipmap/ic_launcher"` | 앱 아이콘 채점 (0.5) |
| `<application>`에 `android:label="@string/app_name"` | 앱 이름 채점 (0.5) |
| `<activity>`에 `android:screenOrientation="portrait"` | 화면 회전 시 깨짐·입력값 초기화 방지 |

## ✅ 실행해서 확인

1. 위쪽 기기 선택에서 **Pixel 5 API 33** AVD 선택 → ▶ Run
2. 홈 화면(앱 서랍)으로 나가서 확인
   - [ ] 아이콘이 `app_icon.png` 그림이다
   - [ ] 아이콘 아래 이름이 **Daily Tarot** 이다
3. 앱을 실행한 채로 에뮬레이터 오른쪽 도구막대의 **회전 버튼** 클릭
   - [ ] 화면이 돌아가지 않고 세로로 유지된다
