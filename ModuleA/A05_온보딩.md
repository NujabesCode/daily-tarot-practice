# A05. 온보딩 화면

![](../images/ModuleA/100_onboarding.png)

## 채점 포인트

| UI 요소 (각 0.2) | 요구사항 (각 0.4) |
|---|---|
| 그라디언트 배경 | 앱 시작 시 그라디언트 배경 표시 |
| 달 그래픽 | 달·구름이 **2초 이내** 애니메이션 |
| Daily Tarot 로고 | 로고와 문구가 **2초 이내** 애니메이션 |
| 작은 로고 그래픽 | 시작하기 버튼이 **2초 이내** 애니메이션 |
| "운명을 엿볼 시간이에요." (중앙 정렬) | 요소가 **각각 다른 시간에** 애니메이션 |
| 시작하기 버튼 (">" 포함) | 시작하기 → 정보 입력 화면 |
| 구름 그래픽 (아래) | |

주관 "온보딩 애니메이션 완성도" 1.5점도 여기서 결정됩니다.

## 애니메이션 시간표 (모두 1.9초 안에 끝)

```
0.0s ─ 달: 왼쪽 위 바깥에서 굴러 들어오며 나타남 (0.9s)
0.3s ─ 구름: 아래에서 떠오름 (1.0s)
0.7s ─ 로고 + 문구: 살짝 커지면서 나타남 (0.8s)
1.2s ─ 시작하기 버튼: 아래에서 올라오며 나타남 (0.7s)
```

## 따라하기

새 파일 `OnboardingScreen.kt`

```kotlin
package com.example.dailytarot

import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.Spacer
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.height
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.graphicsLayer
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.text.style.TextAlign
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp

@Composable
fun OnboardingScreen(onStart: () -> Unit) {
    // 요소마다 시작 시간을 다르게
    val moon = rememberAppear(delayMillis = 0, durationMillis = 900)
    val cloud = rememberAppear(delayMillis = 300, durationMillis = 1000)
    val logo = rememberAppear(delayMillis = 700, durationMillis = 800)
    val button = rememberAppear(delayMillis = 1200, durationMillis = 700)

    TarotBackground(
        moonModifier = Modifier.graphicsLayer {
            alpha = moon
            translationX = (1 - moon) * -80.dp.toPx()
            translationY = (1 - moon) * -80.dp.toPx()
            rotationZ = (1 - moon) * -90f
        },
        cloudModifier = Modifier.graphicsLayer {
            alpha = cloud
            translationY = (1 - cloud) * 120.dp.toPx()
        }
    ) {
        Column(Modifier.fillMaxSize(), horizontalAlignment = Alignment.CenterHorizontally) {
            Spacer(Modifier.weight(0.9f))

            Column(
                horizontalAlignment = Alignment.CenterHorizontally,
                modifier = Modifier.graphicsLayer {
                    alpha = logo
                    scaleX = 0.85f + 0.15f * logo
                    scaleY = 0.85f + 0.15f * logo
                    translationY = (1 - logo) * 30.dp.toPx()
                }
            ) {
                DailyTarotLogo()
                Spacer(Modifier.height(8.dp))
                Text(
                    "운명을 엿볼 시간이에요.",
                    color = Color.White,
                    fontFamily = Myeongjo,
                    fontWeight = FontWeight.Bold,
                    fontSize = 16.sp,
                    textAlign = TextAlign.Center
                )
            }

            Spacer(Modifier.weight(0.7f))

            GlowButton(
                text = "시작하기",
                onClick = onStart,
                modifier = Modifier.graphicsLayer {
                    alpha = button
                    translationY = (1 - button) * 60.dp.toPx()
                }
            )

            Spacer(Modifier.weight(1.3f))
        }
    }
}
```

## App.kt 연결

`App.kt`의 `when` 안에서 한 줄을 바꿉니다.

```kotlin
// 전
Screen.Onboarding -> Placeholder("온보딩") { nav.go(Screen.Name) }
// 후
Screen.Onboarding -> OnboardingScreen(onStart = { nav.go(Screen.Name) })
```

## 핵심 설명

- `graphicsLayer { }` 안의 값은 **그리기 직전에만** 적용됩니다. 레이아웃(위치 계산)은 변하지 않으므로 버튼이 움직여도 다른 요소가 밀리지 않습니다.
- `(1 - p) * 거리`: p가 0일 때 "거리"만큼 떨어져 있다가, p가 1이 되면 0(제자리)이 됩니다. **애니메이션 공식의 기본형**이니 외워 두세요.
- `Spacer(Modifier.weight(...))`: 화면 높이가 달라도 비율대로 배치됩니다. 프로토타입에서 로고는 화면 약 1/3, 버튼은 약 2/3 지점입니다.

## ✅ 실행해서 확인
- [ ] 앱을 켜면 보라 그라데이션 배경
- [ ] 달 → 구름 → 로고·문구 → 버튼 순서로 **각각 다른 시간에** 나타난다
- [ ] 2초 안에 모두 끝난다 (속으로 "하나, 둘" 세어 보기)
- [ ] 시작하기 → 다음 화면으로 이동

> 💡 **변형 대비**: "3초 이내", "로고가 위에서 떨어지도록" 같은 조건이 바뀌면 `delayMillis`, `durationMillis`, `translationY` 부호만 바꾸면 됩니다.
