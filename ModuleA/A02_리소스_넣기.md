# A02. 리소스 넣기 (이미지 · 폰트 · 아이콘)

## 목표
제공 파일을 프로젝트에 넣고, 코드에서 `R.drawable.moon`, `R.font.nanum_myeongjo`처럼 부를 수 있게 합니다.
Module B·C에서 쓸 이미지도 **지금 한 번에** 넣어 둡니다. (다음 모듈은 이 프로젝트를 복사해서 시작)

## 리소스 이름 규칙 (중요)

안드로이드 리소스 파일 이름은 **영어 소문자, 숫자, 밑줄(_)만** 가능하고 **숫자로 시작하면 안 됩니다.**

| 제공 파일 | 넣을 이름 |
|---|---|
| `Daily Tarot.png` | `daily_tarot.png` ← 대문자·공백 때문에 **이름 변경 필수** |
| `1_magician.png` 등 카드 9장 | drawable에 넣지 않음 → Module B에서 `assets`에 넣음 (숫자로 시작하므로) |

## 1) 이미지 → `drawable-nodpi`

1. 프로젝트 창 위쪽 보기 방식을 **Android → Project**로 바꿉니다.
2. `app/src/main/res` 오른쪽 클릭 → **New → Directory** → `drawable-nodpi`
3. 탐색기에서 아래 파일을 복사 → `drawable-nodpi`에 붙여넣기

```
moon.png
cloud.png
daily_tarot.png          ← "Daily Tarot.png" 이름 바꿔서
graphic.png              ← 로고 아래 작은 무늬
tarot_card_back.png      ← (Module C)
daily_tarot_soul_card.png, love_tarot.png, fruit_tarot.png, daily_master.png  ← (Module B)
```

> 💡 왜 `drawable-nodpi`? 그냥 `drawable`에 넣으면 저해상도 이미지로 취급돼서 Pixel 5에서 **2.75배로 확대된 큰 비트맵**이 만들어집니다. `nodpi`는 원본 크기 그대로 써서 메모리를 아낍니다.

## 2) 폰트 → `res/font`

1. `나눔명조.zip`, `Noto_Sans_KR.zip` 압축을 풉니다.
2. `res` 오른쪽 클릭 → **New → Android Resource Directory** → Resource type: **font** → OK
3. 아래 파일을 복사해서 **이름을 바꿔** 넣습니다.

| 원본 | 넣을 이름 |
|---|---|
| `NanumFontSetup_TTF_MYUNGJO/NanumMyeongjo.ttf` | `nanum_myeongjo.ttf` |
| `NanumFontSetup_TTF_MYUNGJO/NanumMyeongjoBold.ttf` | `nanum_myeongjo_bold.ttf` |
| `static/NotoSansKR-Regular.ttf` | `noto_sans_kr_regular.ttf` |
| `static/NotoSansKR-Medium.ttf` | `noto_sans_kr_medium.ttf` |
| `static/NotoSansKR-Bold.ttf` | `noto_sans_kr_bold.ttf` |

프로토타입을 보면 제목·안내 문구는 **명조(나눔명조)**, 버튼·입력칸·작은 글씨는 **고딕(Noto Sans KR)** 입니다.

## 3) SVG 아이콘 → Vector Asset

`res/drawable` 오른쪽 클릭 → **New → Vector Asset** → Asset Type: **Local file (SVG, PSD)** → Path에서 SVG 선택 → Name 입력 → Next → Finish. 세 번 반복합니다.

| SVG | Name |
|---|---|
| `arrow_back_ios_new_24dp_…svg` | `ic_arrow_back` |
| `male_24dp_…svg` | `ic_male` |
| `female_24dp_…svg` | `ic_female` |

> 💡 `>` 모양 화살표는 따로 없습니다. `ic_arrow_back`을 **180도 돌려서** 씁니다 (A03).

## 최종 모습

```
app/src/main/res/
  drawable/        ic_arrow_back.xml, ic_male.xml, ic_female.xml (+ 기본 파일)
  drawable-nodpi/  moon.png, cloud.png, daily_tarot.png, graphic.png, tarot_card_back.png,
                   daily_tarot_soul_card.png, love_tarot.png, fruit_tarot.png, daily_master.png
  font/            nanum_myeongjo.ttf, nanum_myeongjo_bold.ttf,
                   noto_sans_kr_regular.ttf, noto_sans_kr_medium.ttf, noto_sans_kr_bold.ttf
```

## ✅ 확인

- [ ] **Build → Make Project** (Ctrl + F9) 가 에러 없이 끝난다
  - 에러 `'D' is not a valid file-based resource name character` → 이름에 대문자/공백이 남아 있음
  - 에러 `... file name must end with .xml or .png` → 폰트를 font가 아닌 다른 폴더에 넣음
