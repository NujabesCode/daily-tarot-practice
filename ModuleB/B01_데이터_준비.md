# B01. 데이터 준비 (JSON · 카드 이미지 · 소울 넘버)

## 목표
- `soul_cards_data.json`을 읽어서 카드 목록으로 만듭니다. **Gson 같은 외부 라이브러리 없이** 안드로이드 기본 `org.json`을 씁니다.
- JSON의 `"image": "1_magician.png"`를 **그대로** 써서 이미지를 불러옵니다.
- 과제의 소울 넘버 공식을 함수로 만듭니다.

## 1) assets 폴더 만들기

1. `app` 오른쪽 클릭 → **New → Folder → Assets Folder** → Finish
   → `app/src/main/assets` 가 생깁니다.
2. 아래처럼 파일을 넣습니다.

```
app/src/main/assets/
  soul_cards_data.json          ← ModuleB/data/
  soul_card_preview.txt         ← 아래 2)에서 직접 만듦
  tarot_cards/                  ← 폴더 새로 만들기
    1_magician.png … 9_hermit.png   ← 공통제공파일/images/tarot_cards/
```

> 💡 **왜 drawable이 아니라 assets?** 카드 파일명이 숫자로 시작해서 drawable에 넣을 수 없습니다.
> assets는 이름 제한이 없고, JSON의 `image` 값으로 **바로** 열 수 있어서 "JSON 데이터 사용" 채점 항목에도 딱 맞습니다.

## 2) soul_card_preview.txt 만들기

과제 PDF는 소울카드 본문에 `soul_card_preview.txt`를 쓰라고 하지만 **제공 파일에는 없습니다.**
(대회 당일 제공되면 그 파일을 쓰세요.) 프로토타입 문구를 그대로 옮겨 만듭니다.

`assets` 오른쪽 클릭 → **New → File** → `soul_card_preview.txt`

```
[소울 넘버]는 생년월일의 숫자를 모두 더해
얻는 최종적인 한 자리 숫자로,
당신의 핵심적인 에너지와 삶의 테마를 나타냅니다.
이 소울 넘버에 해당하는
메이저 아르카나 타로 카드가 바로 [소울 카드]이며,
이는 당신의 타고난 성격, 기질,
그리고 삶의 목적을 상징합니다.
즉, 소울 넘버는 당신의 [영혼의 번호]이고,
소울 카드는 그 번호가 의미하는
[영혼의 본질]을 보여주는 상징인 셈입니다.
```

`[ ]`로 감싼 부분은 프로토타입에서 **노란색**인 글자입니다. B05에서 `[ ]`를 찾아 노란색으로 바꿔 보여 줍니다.

## 3) TarotData.kt

새 파일 `TarotData.kt`

```kotlin
package com.example.dailytarot

import android.content.Context
import android.graphics.BitmapFactory
import androidx.compose.runtime.Composable
import androidx.compose.runtime.remember
import androidx.compose.ui.graphics.ImageBitmap
import androidx.compose.ui.graphics.asImageBitmap
import androidx.compose.ui.platform.LocalContext
import org.json.JSONArray
import java.time.LocalDate

// JSON 한 칸 = 카드 한 장
data class TarotCard(
    val number: Int,
    val name: String,
    val storytelling: String,
    val image: String
)

object TarotData {
    private val cache = mutableMapOf<String, List<TarotCard>>()

    // assets 안의 JSON 파일을 카드 목록으로 (한 번 읽으면 기억해 둠)
    fun load(context: Context, fileName: String): List<TarotCard> = cache.getOrPut(fileName) {
        val text = context.assets.open(fileName).bufferedReader().use { it.readText() }
        val array = JSONArray(text)
        List(array.length()) { i ->
            val o = array.getJSONObject(i)
            TarotCard(
                number = o.getInt("number"),
                name = o.getString("name"),
                storytelling = o.getString("storytelling"),
                image = o.getString("image")
            )
        }
    }
}

// 과제 공식: 연+월+일 → 각 자리를 더하기를 한 자리가 될 때까지
// 1993-07-29 → 1993+7+29 = 2029 → 2+0+2+9 = 13 → 1+3 = 4
fun soulNumber(date: LocalDate): Int {
    var n = date.year + date.monthValue + date.dayOfMonth
    while (n >= 10) {
        n = n.toString().sumOf { it - '0' }
    }
    return n
}

// assets/tarot_cards/ 의 카드 그림 불러오기
@Composable
fun rememberCardImage(fileName: String): ImageBitmap {
    val context = LocalContext.current
    return remember(fileName) {
        context.assets.open("tarot_cards/$fileName").use { BitmapFactory.decodeStream(it) }.asImageBitmap()
    }
}
```

## 핵심 설명

- **`org.json.JSONArray`**: 안드로이드에 처음부터 들어 있는 JSON 도구입니다. 의존성 추가가 필요 없습니다.
- **`it - '0'`**: 글자 `'7'`에서 `'0'`을 빼면 숫자 `7`이 됩니다. `"2029".sumOf { it - '0' }` = 2+0+2+9 = 13.
- 결과는 항상 **1~9** 이므로 JSON에도 카드가 9장(1~9번)입니다.

## ✅ 확인 (계산 연습)

손으로 먼저 계산하고, B06 완성 후 앱으로 확인합니다.

| 생년월일 | 계산 | 카드 |
|---|---|---|
| 1993.07.29 | 1993+7+29 = 2029 → 13 → **4** | 황제 |
| 2026.04.01 | 2026+4+1 = 2031 → **6** | 연인 |
| 2025.04.01 | 2025+4+1 = 2030 → **5** | 교황 |
| 2000.01.01 | 2000+1+1 = 2002 → **4** | 황제 |
| 1999.12.31 | 1999+12+31 = 2042 → 8 → **8** | 힘 |
