# B07. Module B 제출 연습 · 채점기준 체크리스트

## 1. 제출 연습 (15분 안에)

A11과 같은 순서입니다. 이번에는 **보지 않고** 해 보세요.

1. **Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`
2. 프로젝트 루트(`DailyTarot_B`)에 **`Module_B_XXX.apk`** 로 복사 (A의 APK가 남아 있다면 지우기)
3. 에뮬레이터에서 앱 **삭제** → APK 드래그 설치 → 처음부터 끝까지 실행
4. Android Studio 닫기 → 프로젝트 폴더째 USB → USB에서 APK 위치 확인

> 💡 **달 개수 유지 확인은 APK로**: 앱을 지웠다 다시 설치하면 저장값이 사라지는 게 정상입니다. "다시 접속해도 유지"는 **앱 종료 → 다시 실행**으로 확인합니다.

### 이번 모듈에서 자주 하는 실수

| 실수 | 결과 |
|---|---|
| assets 폴더를 `app/src/main` 이 아닌 곳에 만듦 | 앱 실행 즉시 종료 (`FileNotFoundException`) |
| `soul_cards_data.json` 이름 오타 | 나의 소울카드에서 앱 종료 |
| 마지막 상품을 프로토타입대로 350개로 만듦 | 채점표 문구(300개) 불일치 |
| 달 부족 확인을 안 해 봄 | 차감 로직이 음수로 내려가도 모름 |

## 3. 변형 문제 대비

| 변형 | 어디를 고치나 |
|---|---|
| 소울카드 비용 10 → 15개 | `onFind`의 `10` 두 곳 + 버튼 문구 |
