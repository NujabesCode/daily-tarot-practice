### 파일 맨 아래에 MoonStore 추가

```kotlin
// ───────── 달 개수 (앱을 꺼도 유지) ─────────
class MoonStore(context: Context) {
    private val prefs = context.getSharedPreferences("daily_tarot", Context.MODE_PRIVATE)

    var count by mutableIntStateOf(prefs.getInt("moons", 0))
        private set

    fun add(amount: Int) {
        count += amount
        prefs.edit().putInt("moons", count).apply()
    }

    // 모자라면 false, 충분하면 차감하고 true
    fun use(amount: Int): Boolean {
        if (count < amount) return false
        count -= amount
        prefs.edit().putInt("moons", count).apply()
        return true
    }
}
```

맨 위 import에 추가:

```kotlin
import android.content.Context
import androidx.compose.runtime.mutableIntStateOf
```

그리고 `when` 안에 새 화면 3개를 **임시 화면**(A04의 `Placeholder`)으로 추가합니다.

```kotlin
Screen.Home -> EmptyHomeScreen()
Screen.Charge -> Placeholder("달 충전 (보유 ${moons.count}개)") { moons.add(25) }
Screen.SoulCard -> Placeholder("소울카드") { nav.back() }

```

`MySoulCard`는 `data class`(값을 가진 화면)라서 `is`를 붙입니다.

## 핵심 설명

- **SharedPreferences**: 앱 안에 작은 값을 저장하는 기본 저장소. 앱을 지우기 전까지 남습니다.
- **`mutableIntStateOf`**: 값이 바뀌면 그 값을 보여 주는 화면(홈의 달 개수, 충전 화면의 보유 개수)이 **자동으로 다시 그려집니다.** → "충전 완료 시 보유 개수 갱신" 요구사항이 저절로 해결됩니다.
- **처음 값 0**: 프로토타입에는 10개로 보이지만, 0으로 시작해야 "달이 부족한 경우 안내 메시지"를 바로 확인할 수 있습니다. 10으로 시작하고 싶다면 `getInt("moons", 10)`.
