# C01. 준비 · 화면 등록

## 1) JSON 2개 넣기

`app/src/main/assets/`에 복사합니다.

```
assets/
  soul_cards_data.json
  fruit_tarot_cards_data.json     ← ModuleC/data/
  loves_tarot_cards_data.json     ← ModuleC/data/
  soul_card_preview.txt
  tarot_cards/ (9장)
```

세 JSON 모두 **같은 모양**(`number`, `name`, `storytelling`, `image`)이고 이미지도 같은 9장을 씁니다.
그래서 B01의 `TarotData.load()`, `rememberCardImage()`를 그대로 씁니다. 본문(`storytelling`)만 다릅니다.

## 2) AppState.kt — 화면 3개 추가

`sealed class Screen` 안에 추가:

```kotlin
    // ── Module C ──
    data object FruitTarot : Screen()
    data object LoveTarot : Screen()
    data class TarotResult(val kind: TarotKind, val card: TarotCard) : Screen()
```

파일 아래쪽(클래스 밖)에 추가:

```kotlin
// 어떤 타로인지 = 어떤 JSON을 쓰는지
enum class TarotKind(val file: String) {
    Fruit("fruit_tarot_cards_data.json"),
    Love("loves_tarot_cards_data.json")
}
```

## 3) App.kt — 홈 연결 + 임시 화면

홈의 두 줄을 토스트에서 **화면 이동**으로 바꿉니다.

```kotlin
// 전 (Module B)
onLoveTarot = { context.toast("인연 타로는 지금 준비 중이에요. 조금만 기다려주세요!") },
onFruitTarot = { context.toast("열매 타로는 지금 준비 중이에요. 조금만 기다려주세요!") },
// 후 (Module C)
onLoveTarot = { nav.go(Screen.LoveTarot) },
onFruitTarot = { nav.go(Screen.FruitTarot) },
```

`when` 맨 아래에 임시 화면 3개:

```kotlin
// ── Module C ──
Screen.FruitTarot -> Placeholder("열매 타로") {
    nav.go(Screen.TarotResult(TarotKind.Fruit, TarotData.load(context, TarotKind.Fruit.file).random()))
}
Screen.LoveTarot -> Placeholder("인연 타로") {
    nav.go(Screen.TarotResult(TarotKind.Love, TarotData.load(context, TarotKind.Love.file).random()))
}
is Screen.TarotResult -> Placeholder("${screen.card.number}. ${screen.card.name}") { nav.reset(Screen.Home) }
```
