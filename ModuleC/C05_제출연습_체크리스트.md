## 3. 변형 문제 대비

| 변형 | 어디를 고치나 |
|---|---|
| 카드 **3장** 고르기 (과거·현재·미래) | `FruitTarotScreen`에 `selected` 리스트, 3장 차면 이동. `Screen.TarotResult`에 `List<TarotCard>` |
| 타로 보기에 **달 5개** 필요 | 홈에서 이동 전에 `moons.use(5)` 검사 (B05 방식) |
| 결과 화면에 **다시 뽑기** 버튼 | `nav.back()` |
| 인연 타로 보이는 카드 **5장** | `step = maxWidth / 5`, `cardW`를 조금 키우기 |
| 셔플 버튼을 인연 타로에도 | `deck`을 `mutableStateOf`로, 셔플 시 `listState.animateScrollToItem(0)` |
| 뽑은 결과 **기록 보기** | `SharedPreferences`에 번호 목록 저장 (B02 방식) |
